# STM32 FreeRTOS Reliability & Debug Demo

STM32F446RE + FreeRTOS reliability and debug demo for embedded interview portfolio.

## Hardware
- Board: NUCLEO-F446RE
- MCU: STM32F446RE (Cortex-M4, 180MHz)
- Flash: 512KB / RAM: 128KB

## Environment
- STM32CubeIDE 2.1.1
- STM32CubeMX 6.16.1
- FreeRTOS CMSIS-RTOS V2
